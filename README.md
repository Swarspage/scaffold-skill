# Scroll-3D Experiences

Version 0.3.0 — a focused skill for object-led, scroll-driven WebGL experiences. It pairs the included framework-neutral Three.js starter with an original design-decision workflow: product and asset evidence, art direction, composition, choreography, responsive treatment, and visual review.

Start with [SKILL.md](SKILL.md). The runnable example remains in `templates/starter`; the JSON examples and validators remain in `assets/` and `scripts/`.

## Validate the skill

```bash
node scripts/validate-skill.mjs
node scripts/validate-spec.mjs assets/examples/watch.json
```

For the browser smoke test, follow `references/09-verification.md` from the project that uses the starter. A successful smoke test is not a visual review.
