# Art direction

Write a creative thesis that connects the object, visual world, lighting, type, interface, and motion. “Dark and futuristic” is not a thesis.

When direction is ambiguous, propose three choices. Each must name a concept, intended feeling, palette roles, type pairing, materials, lighting, camera/motion character, page composition, and the main risk.

Example contrasts:

- **Industrial instrument:** disciplined grid, restrained neutral metal, hard side key, measured mono labels, deliberate station-to-station camera moves. Risk: sterile density.
- **Luxury editorial object:** ample negative space, high-contrast display paired with quiet body text, soft sculpting light, slow object reveal. Risk: copy obscures the product.
- **Organic future lab:** translucent surfaces, warm/cool environmental separation, curved spatial framing, buoyant but controlled camera drift. Risk: decorative glow hides weak silhouette.

Respect supplied brand rules. A coherent combination shares a logic: typography, materials, geometry, and motion should reinforce the same thesis.
