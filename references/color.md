# Color across DOM and scene

Name roles: ground, surface, primary text, muted text, structural accent, and optional emissive accent. Choose palettes by relationship—monochromatic, analogous, complementary, or temperature contrast—not a random gradient.

CSS overlay colors and Three.js material/light colors affect one image. Test contrast against the rendered canvas at each scroll station; a token that passes on a swatch can fail over moving specular light. Reserve emissive color for a small narrative cue. Gradients should describe atmosphere or depth, not substitute for direction.
