# Responsive experience

At narrow widths, re-compose instead of shrinking desktop. Define mobile camera waypoints, revise object scale/crop, shorten pins, reduce expensive effects, and preserve a visible hero object. Do not hide the canvas as a routine breakpoint fix.

For reduced motion, show essential information immediately, stabilize the object or use a deliberate poster, disable nonessential parallax/scrub/particles, and retain semantic DOM controls. Use a static fallback only for unavailable WebGL or demonstrated budget failure, and state the reason.
