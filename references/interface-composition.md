# Compose the complete experience

The DOM and scene are one composition. Start with the opening viewport: the visitor should recognize the object, understand the proposition, and have a clear next action or exploration cue.

Use foreground, midground, and background intentionally. Preserve negative space around the object and keep critical geometry clear of navigation, text, cards, and CTA controls. Let sections change density and scale across the scroll: arrival, orientation, evidence/anatomy, detail, action, close. Use cards, metadata, and overlays only when they advance the selected mode.

Mobile is a separate arrangement: reserve an object stage, move copy into a readable vertical flow, and keep touch controls large and reachable.
