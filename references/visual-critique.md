# Visual critique scorecard

Open the captured images. Score each category 0–3 with observed evidence, a priority, and a corrective action: object identity, material/light, camera framing, hierarchy/legibility, motion pacing, DOM/scene coherence, mobile, accessibility, originality, and brief fit.

| Score | Meaning |
| --- | --- |
| 0 | blocking failure or missing requirement |
| 1 | visible weakness that changes comprehension or trust |
| 2 | sound, with a clear improvement available |
| 3 | convincingly serves the brief |

Rank fixes P0 (ship blocker), P1 (material), P2 (noticeable), P3 (polish). A P0 in object identity, mobile visibility, essential accessibility, or functional interaction blocks shipment regardless of averages. Batch up to three high-value fixes, recapture, and repeat no more than three rounds. If screenshot viewing is unavailable, record `NOT TESTED`; browser success is not visual critique.
